# Student Productivity Prediction - ML Diary

## 📚 Project Overview

**Student Productivity Prediction** is a Machine Learning project that classifies student productivity into **Low/Med/High** categories based on 8 key factors. This repository contains a  ML diary** documenting the complete development journey.

## 🎯 Project Details

- **Model**: XGBoost Classifier
- **Accuracy**: 89% on test dataset
- **Classification**: Low/Medium/High productivity levels
- **Features**: Study Hours, Sleep, Attendance, Screen Time, Previous Scores, Study Consistency, Extracurricular Activities, Class Participation
